Date: 2026-07-15
Activity: Repository Initialization & Milestone 1 (Core Extension & Monorepo Setup)

1. Monorepo Setup
   - Created root package.json defining npm workspaces for 'apps/backend', 'apps/extension', and 'packages/shared'.
   - Setup a base root tsconfig.json targeting ES2022 with NodeNext module resolution.
   - Initialized a .gitignore file to exclude node_modules, build outputs (dist/), environment files, and this PROJECT_GUIDE.txt file.

2. Shared Package (@leetcoach/shared)
   - Created tsconfig.json and package.json configuration files.
   - Defined TypeScript models in 'src/types/index.ts' for:
     * LeetCodeSyncPayload: The format scraped from LeetCode.
     * ReviewRequestPayload / ReviewResponsePayload: Inputs and outputs for spaced repetition updates.
     * UserProblemData / DashboardData: Interface schemas between backend database records and the React extension frontend.
   - Built the shared package using tsc.

3. Chrome Extension Package (@leetcoach/extension)
   - Created Manifest V3 'manifest.json' (saved in 'public/' so Vite bundles it automatically) with permissions: storage, activeTab, sidePanel.
   - Configured 'vite.config.ts' with a Rollup custom entry points function to compile unhashed file names for background.js and content.js, while using standard hashed names for popup/sidepanel scripts.
   - Configured Tailwind CSS, PostCSS, and global CSS directives (with custom dark-themed background colors).
   - In content script ('src/content/index.ts'):
     * Implemented DOM MutationObserver to detect LeetCode's 'Accepted' banner.
     * Implemented an injected script mechanism to extract Monaco Editor's raw code buffers since content scripts operate in an isolated context.
     * Coded a scraper to capture problem title slugs, difficulty class names, and topic tags.
   - In background worker ('src/background/index.ts'):
     * Configured sidepanel actions to trigger side panel display.
     * Managed chrome.storage.local queues for local solution preservation before syncing to the backend.
   - Developed skeleton React components:
     * Popup ('src/popup/main.tsx'): simple button allowing explicit sidepanel expansion.
     * Sidepanel ('src/sidepanel/main.tsx'): complete multi-tab layout (Queue, Dashboard, Chat, Settings) styled with tailwind classes and Lucide icons.
   - Fixed strict compiler issues (unused variables in MutationObserver and validation blocks) and verified clean build output.

Date: 2026-07-15
Activity: Milestone 2 (Backend Foundation, Schema, & JWT Auth Integration)

1. Express.js Backend Boilerplate
   - Created Express application entry point ('apps/backend/src/index.ts') and configuration loader ('src/config/index.ts').
   - Registered CORS, JSON body parser, dynamic port mapping, and global error handling middleware ('src/middleware/error.ts').

2. Database schema & pgvector Configuration
   - Configured connection client in 'src/db/index.ts'.
   - Setup Drizzle ORM config ('drizzle.config.ts') supporting PostgreSQL dialects.
   - Defined database schema ('src/db/schema.ts') consisting of:
     * users: authentication records.
     * problems: cache of general problem descriptors.
     * user_problems: user-specific solution variables (SM-2 state, notes, summaries).
     * code_submissions: compilation history logs.
     * mistakes: categorized error logs.
     * review_logs: spaced repetition history entries.
     * embeddings: pgvector vector(768) columns with custom HNSW index parameters.
   - Upgraded Drizzle dependency versions and successfully generated SQL migrations in 'src/db/migrations/'.
   - Created 'docker-compose.yml' in root to launch a containerized Postgres pgvector database.

3. Authentication Services & Controllers
   - Created sign-up, sign-in, and current user profile controllers ('src/controllers/auth.controller.ts') utilizing bcryptjs.
   - Implemented request context JWT verification middleware ('src/middleware/auth.ts').
   - Created auth routers and registered them on the API router prefix ('/api/auth/').

4. Chrome Extension Auth Interface
   - Created React Context state provider ('AuthContext.tsx') and hook ('useAuth') managing JWT cookies and user records in chrome.storage.local.
   - Developed React view layouts for login ('LoginView.tsx') and signup ('SignupView.tsx') interfaces with clean form validations.
   - Programmed an 'AuthGuard.tsx' barrier component to block dashboard access for guest users.
   - Verified that both packages compile and build successfully with zero errors.

Date: 2026-07-15
Activity: Milestone 3 (Spaced Repetition Core & Extension Deck UI)

1. SM-2 Spaced Repetition Engine
   - Implemented custom spacing logic ('apps/backend/src/services/sm2.service.ts') supporting:
     * Recall quality ratings (Green: 5, Yellow: 3, Red: 1).
     * Quality-based Ease Factor calculations and repetition step increments.
     * Problem difficulty modifiers (Hard = 0.8x interval, Easy = 1.2x interval).

2. Spaced Repetition API Controllers & Routers
   - Coded route handlers ('src/controllers/problems.controller.ts') for:
     * syncProblem: matching and caching global metadata, creating junction logs, and logging codes.
     * getRevisionQueue: retrieving user problems due for revision (nextReview <= now) with joins on problem info and latest codes.
     * reviewProblem: running SM-2 engine, saving review logs, and scheduling next review timestamps.
     * updateNotes: saving text summaries.
     * addMistake: logging categorized mistakes.
   - Mounted routes on '/api/problems' sub-prefix.

3. Extension Space Repetition UI Components
   - Built 'QueueContext.tsx' to manage state lists and API synchronization within the browser sidepanel.
   - Built 'RevisionQueueView.tsx' to list current due tasks with topic chips.
   - Built 'ActiveReviewCard.tsx' offering:
     * Duration timer.
     * Toggleable code panel containing the last accepted solution.
     * Real-time concepts text saving with status overlays.
     * Mistakes listing and creation forms.
     * Spacing recall feedback selectors.
   - Wrapped sidepanel UI entry point ('sidepanel/main.tsx') in QueueProvider and added tab transitions.
   - Cleared compiler unused imports checks and successfully compiled the extension.
